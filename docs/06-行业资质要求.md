# 行业资质要求

## 概述

不同行业注册微信支付商户号需要提供不同的特殊资质证明。本文列出常见行业的要求。

## 行业资质清单

### 餐饮类

| 行业 | 必需资质 | 说明 |
|------|----------|------|
| 餐厅、小吃店 | 食品经营许可证 | 餐饮服务许可证已合并 |
| 外卖平台 | 食品经营许可证 + 外卖平台合作协议 | - |
| 奶茶、饮品 | 食品经营许可证 | - |
| 烘焙店 | 食品经营许可证 | - |

## 资质有效期

| 资质类型 | 有效期 | 过期处理 |
|----------|--------|----------|
| 营业执照 | 长期（除非变更） | 及时更新 |
| 食品经营许可证 | 5年 | 提前续期 |
| 药品经营许可证 | 5年 | 提前续期 |
| 医疗机构执业许可证 | 长期 | 定期校验 |
| ICP许可证 | 5年 | 提前续期 |
| 烟草专卖零售许可证 | 定期 | 及时续期 |

## 资质变更

### 需要更新资质的情况

1. 营业执照信息变更（名称、地址、法人等）
2. 经营场所变更
3. 经营范围变更
4. 资质证书到期续期
5. 行业类目调整

### 更新流程

1. 登录微信支付商户平台
2. 进入「商户信息」→「基本信息」
3. 选择需要更新的资质类型
4. 上传新的资质证书
5. 提交审核

## 常见问题

### Q1：没有特殊资质怎么办？

**答**：如果经营内容涉及特殊行业但暂时没有资质，建议：
1. 先咨询当地主管部门了解办证流程
2. 暂时下架相关商品/服务
3. 等待资质办理完成后再上架

### Q2：资质与实际经营不符？

**答**：如果营业执照经营范围与实际经营不符：
1. 先去工商部门变更营业执照
2. 确保经营范围包含实际经营内容
3. 然后再进行商户号申诉

### Q3：多个行业需要多个商户号吗？

**答**：建议根据实际情况决定：
1. 如果是同一类目下的多品种经营，一个商户号即可
2. 如果是完全不同的行业，建议分开注册
3. 注意不要跨类目经营
