## 核心功能

### 1. 商户号申诉

支持微信支付和支付宝商户号的各类风控申诉：
- 交易拦截
- 支付权限关闭
- 资金冻结
- 调单核查

### 2. 闲鱼管家API

集成闲鱼管家开放平台API：
- 查询店铺列表
- 查询订单列表
- 查询订单详情
- 订单状态同步

### 3. 知识库问答

基于RAG技术的智能问答：
- 商户号基础知识
- 费率结算问题
- 注册流程指导
- 风控预防建议

## 技术支持

### API服务

- 服务文件：`server/services/xianGuanService.js`
- RAG服务：`server/ai/rag/ragService.js`
- 知识库：`server/knowledgeBase.js`

### 相关路由

| 路由 | 方法 | 说明 |
|------|------|------|
| `/api/xianguan/shops` | GET | 获取闲鱼管家店铺列表 |
| `/api/orders/from-system` | GET | 获取订单列表 |
| `/api/orders/from-system/:orderNo` | GET | 获取订单详情 |
