# 合规使用指南

## 概述

本指南旨在帮助用户合法、合规地使用商户号申诉助手系统。

---

## 一、法律框架

### 1.1 相关法律法规

使用本系统时，请遵守以下法律法规：

| 法律名称 | 适用范围 |
|----------|----------|
| 《网络安全法》 | 网络安全、数据保护 |
| 《个人信息保护法》 | 用户个人信息收集、使用、存储 |
| 《电子商务法》 | 电商平台经营规范 |
| 《广告法》 | 服务宣传、推广 |
| 《反不正当竞争法》 | 商业竞争规范 |
| 《支付结算管理办法》 | 支付相关业务 |

### 1.2 平台规则

同时需遵守相关平台规则：
- 微信支付商户平台服务协议
- 支付宝开放平台协议
- 闲鱼管家开放平台协议

## 二、合规使用场景

### 2.1 允许的使用场景

✅ **商户自助申诉**
- 商户本人使用系统提交自己的商户号申诉
- 商户准备真实、完整的申诉材料

✅ **代理申诉服务**
- 获得商户书面授权
- 仅代理提交申诉，不伪造材料
- 服务费用透明合理

✅ **咨询服务**
- 提供申诉流程指导
- 解答申诉政策问题
- 提供整改建议

### 2.2 禁止的使用场景

❌ **伪造材料**
- 伪造营业执照
- 伪造交易凭证
- 伪造授权文件

❌ **冒名申诉**
- 未经授权代理他人申诉
- 冒充他人身份

❌ **规避风控**
- 故意规避微信/支付宝风控系统
- 使用多账号等方式规避监管

❌ **违法经营**
- 从事赌博、诈骗等违法活动
- 为违法活动提供支付服务

## 三、信息安全

### 3.1 数据收集

**最小必要原则**：
- 仅收集申诉所必需的信息
- 不收集与申诉无关的个人信息
- 明确告知用户信息收集目的

**收集的信息类型**：
| 信息类型 | 用途 | 保存期限 |
|----------|------|----------|
| 商户号 | 申诉标识 | 申诉完成后2年 |
| 营业执照 | 资质核实 | 申诉完成后2年 |
| 身份证信息 | 身份核实 | 申诉完成后2年 |
| 交易记录 | 申诉证据 | 申诉完成后2年 |
| 联系方式 | 沟通反馈 | 服务期间 |

### 3.2 数据存储

**安全要求**：
- 数据库密码使用强密码
- 敏感数据加密存储
- 定期备份数据
- 限制数据库访问权限

**加密字段**：
- 手机号
- 身份证号
- API密钥
- 支付密码

### 3.3 数据使用

**使用原则**：
- 仅用于申诉服务
- 未经用户同意不得对外提供
- 不得用于商业变现（除非用户同意）

### 3.4 数据删除

**删除条件**：
- 用户主动要求删除
- 服务终止后一定期限
- 法律法规要求的其他情形

**删除范围**：
- 用户基本信息
- 申诉记录
- 聊天记录

## 四、商户号申诉规范

### 4.1 申诉材料真实性

**核心原则**：所有提交的材料必须真实有效

| 材料类型 | 要求 |
|----------|------|
| 营业执照 | 真实有效，不得伪造 |
| 法人身份证 | 真实有效，与营业执照一致 |
| 门头照片 | 真实拍摄，不得PS |
| 交易凭证 | 真实交易记录 |
| 整改计划 | 实事求是，切实可行 |

### 4.2 虚假材料的法律后果

**民事责任**：
- 侵犯平台权益，承担赔偿责任
- 欺诈商户，承担退赔责任

**行政责任**：
- 违反《网络安全法》，面临罚款
- 违反《个人信息保护法》，面临处罚

**刑事责任**：
- 伪造公文、证件罪
- 诈骗罪
- 侵犯公民个人信息罪

### 4.3 代理申诉规范

**代理条件**：
- 取得商户书面授权
- 明确代理范围和期限
- 签署保密协议

**代理禁止**：
- 不得伪造任何材料
- 不得隐瞒重要事实
- 不得串通风控人员

## 七、风险防控

### 7.1 合规风险识别

| 风险类型 | 识别要点 | 防控措施 |
|----------|----------|----------|
| 材料虚假 | 核实材料真实性 | 建立审核机制 |
| 信息泄露 | 数据访问权限 | 加密存储 |
| 超范围经营 | 确认经营范围 | 资质审查 |
| 投诉风险 | 服务质量 | 提升服务水平 |

### 7.2 应急预案

**信息安全事件**：
1. 立即启动应急预案
2. 评估影响范围
3. 通知受影响用户
4. 向监管部门报告

**合规检查应对**：
1. 配合监管部门检查
2. 提供真实完整资料
3. 及时整改问题
