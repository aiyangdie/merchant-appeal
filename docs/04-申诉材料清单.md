# 申诉材料清单

## 概述

本文档列出商户号申诉所需的各种材料，按类型和用途分类。

## 基础信息材料

| 材料名称 | 说明 | 必需 |
|---------|------|------|
| 商户号 | 微信支付商户号（10位数字） | 是 |
| 公司名称 | 营业执照上的公司全称 | 是 |
| 法人姓名 | 法定代表人姓名 | 是 |
| 法人身份证号 | 法定代表人身份证号码 | 是 |
| 法人手机号 | 法定代表人联系方式 | 是 |
| 联系人姓名 | 日常联系人姓名 | 是 |
| 联系人手机号 | 日常联系人电话 | 是 |
| 公司营业地址 | 实际经营地址 | 是 |

## 证照文件

### 基础证照

| 材料名称 | 说明 | 必需 |
|---------|------|------|
| 营业执照 | 有效期内的营业执照（副本或正本均可） | 是 |
| 法人身份证正反面 | 清晰的身份证照片，确保文字可辨认 | 是 |
| 法人手持身份证照 | 法人手持身份证的半身照 | 是 |

### 经营场所证明

| 材料名称 | 说明 | 条件必需 |
|---------|------|----------|
| 租赁合同 | 经营场所租赁合同 | 线下门店 |
| 产权证明 | 经营场所产权证明 | 自有物业 |
| 场地照片 | 经营场所全景照片 | 是 |

### 特殊行业资质

| 行业 | 所需资质 |
|------|----------|
| 餐饮 | 食品经营许可证、卫生许可证 |
| 医疗 | 医疗机构执业许可证 |
| 教育 | 办学许可证 |
| 旅游 | 旅游业务经营许可证 |
| 物流 | 道路运输经营许可证 |
| 出版 | 出版物经营许可证 |
| 药品 | 药品经营许可证 |
| 烟草 | 烟草专卖零售许可证 |

## 交易凭证材料

### 真实交易证明

| 材料名称 | 说明 | 用途 |
|---------|------|------|
| 订单截图 | 近期真实订单的截图 | 证明交易真实性 |
| 物流单据 | 发货单、物流跟踪截图 | 证明发货履约 |
| 签收记录 | 买家确认收货截图 | 证明完成交易 |
| 收款记录 | 银行流水或支付记录 | 证明资金流向 |

### 特殊情况说明

| 材料名称 | 说明 | 用途 |
|---------|------|------|
| 促销活动说明 | 活动海报、链接、规则 | 解释交易波动 |
| 新店开业证明 | 开业海报、媒体报道 | 解释交易增长 |
| 供货合同 | 与供应商的合同 | 证明货源合法 |
| 进货发票 | 正规渠道进货发票 | 证明商品来源 |

## 整改材料

### 整改计划书

| 内容 | 说明 |
|------|------|
| 问题原因分析 | 详细分析触发风控的原因 |
| 整改措施 | 具体采取的整改措施 |
| 整改时间表 | 预计完成整改的时间节点 |
| 预防方案 | 防止再次触发风控的措施 |

### 承诺书

| 内容 | 说明 |
|------|------|
| 合规承诺 | 承诺严格遵守平台规则 |
| 整改承诺 | 承诺按时完成整改 |
| 责任承担 | 如违规愿意承担责任 |

## 投诉处理材料

### 退款凭证

| 材料名称 | 说明 | 用途 |
|---------|------|------|
| 退款截图 | 每笔投诉的退款截图 | 证明已处理 |
| 退款凭证汇总 | 所有退款的汇总表 | 便于审核 |
| 消费者撤诉截图 | 消费者在投诉页面撤诉的截图 | 证明投诉已解决 |

### 整改后政策

| 材料名称 | 说明 | 用途 |
|---------|------|------|
| 退费政策 | 更完善的退费政策文件 | 整改证明 |
| 客服流程 | 优化后的客服处理流程 | 整改证明 |
| 售后承诺 | 更完善的售后服务承诺 | 整改证明 |

## 材料准备注意事项

### 照片要求

1. **清晰度**：照片必须清晰，文字可辨认
2. **完整性**：确保照片完整，不要有遮挡
3. **真实性**：照片必须真实，禁止PS或伪造
4. **时效性**：尽量使用近期的照片

### 文件要求

1. **格式**：支持jpg、png、pdf格式
2. **大小**：单个文件不超过10MB
3. **命名**：建议使用中文命名便于识别

### 提交前检查

- [ ] 所有必填材料都已准备
- [ ] 材料清晰可辨认
- [ ] 材料真实有效
- [ ] 文件格式符合要求
- [ ] 所有盖章文件已盖章
